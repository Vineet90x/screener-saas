# Screener SaaS

A multi-tenant stock screener. Users define filter rules
(e.g. price > 500 AND volume > 1M), save them, and get
email alerts when a stock starts matching.

**Stack:** Next.js 15 (App Router), TypeScript, PostgreSQL,
Drizzle ORM, Auth.js, Tailwind, Docker

**Status:** In progress — see commit history.
